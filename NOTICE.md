Six files reach `$out` — `config.json`, `model.safetensors`, `tokenizer.json`, `tokenizer_config.json`, `special_tokens_map.json`, `vocab.txt` — each copied from the pinned commit unchanged, and none of them a licence or notice file, so the model directory carries no statement of terms of its own. The weights are fetched when a derivation is built, so evaluating or promoting this repository conveys nothing; serving the built store path conveys an Apache-2.0-licensed model, and Apache-2.0's condition on a copy then falls to whoever serves it, because the output carries no licence text to travel with it.
